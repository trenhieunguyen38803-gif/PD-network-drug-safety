# PD-network-drug-safety

R code for a pharmacovigilance study of drug-pair–event prioritization in Parkinson disease.

## Files

- `01_primary_models.R` — primary analyses
- `02_role_calendar_sensitivity.R` — sensitivity analyses
- `03_confusion_domain_mapping.R` — confusion/delirium domain mapping
- `04_confusion_domain_models.R` — revised-domain analyses
- `05_canada_external_assessment.R` — Canadian external assessment

## Requirements

R packages: `data.table`, `brglm2`

## Data

This repository contains analysis code only. Source pharmacovigilance data are not redistributed here.
